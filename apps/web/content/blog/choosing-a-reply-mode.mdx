## Start in Approval

Kibo drafts every reply and waits for you or a mod to approve it. You see exactly what it would say before chat does.

## Move to Auto when it’s boring

When you’ve approved a stream’s worth of replies without editing any, switch to Auto. Kibo still stays quiet when it isn’t sure.

## Use Silent to learn

Silent mode never posts. It logs what Kibo would have said, which is useful for a big channel testing it for the first time.
