## Check the reply mode

In Approval mode, replies wait for you in the live console. In Silent mode, Kibo never posts.

## Check slow mode

If your chat is in slow mode, Kibo waits like everyone else. Add the bot account as a moderator so it isn’t slowed down.

## Check the connection

If YouTube shows **Needs reconnect** on the Integrations page, reconnect it.
